# Резервная копия Mac Studio

Команда из корня проекта:

```bash
python3 scripts/backup_mac_studio.py
```

По умолчанию создаёт новый каталог `~/Desktop/H3 Studio Backups/H3-Studio-<UTC>`.
Можно указать другой диск через `--destination /путь/к/каталогу`.
Скрипт читает три локальные очереди и останавливается при активном задании.
Копирует `assets`, `results`, `editor_exports`, `editor_projects`, `model-staging`,
`code-backups`, чаты агента, запуски, `draft.json`, базы Studio, очереди, франшиз,
аналитики, вычислений, Context IR и журнала UI, а также LaunchAgent Studio и
конфигурацию SSH-туннеля. Базы копируются через SQLite backup API и проверяются
`PRAGMA integrity_check`. Для каждого файла записываются размер и SHA-256 в
`manifest.json`. Виртуальное окружение, журналы и восстанавливаемые миниатюры
не входят в копию. Закрытый SSH-ключ и HF-токен не копируются.
Копии, созданные до этого исправления, могли не содержать `franchises.sqlite3`;
наличие базы и её записей нужно проверить до восстановления раскладки медиатеки.

Каталог содержит медиа и конфигурацию подключения, поэтому доступ к нему должен
оставаться только у владельца Mac. Эта копия находится на том же компьютере:
для защиты от отказа диска перенесите её на доверенный отдельный носитель.

Восстановление выполняется только после остановки Mac Studio и проверки текущей
очереди. Сначала сохраните текущий каталог данных отдельно. Проверьте
`manifest.json`, затем восстановите базы и каталоги медиа. Конфигурацию туннеля
сверяйте с актуальным GPU-хостом перед использованием; не заменяйте её вслепую.

Для переноса всей Studio на другой Mac используйте
[STUDIO_MAC_TRANSFER.md](STUDIO_MAC_TRANSFER.md): комплект включает исходный код,
установщик LaunchAgent и отдельное восстановление пользовательских данных.
