# Установка H3 Studio

## 1. Studio на Mac — двойной щелчок

1. Скачайте репозиторий (Code → Download ZIP или `git clone`) и распакуйте.
2. Дважды щёлкните **«Установить Studio.command»**. Если macOS не даёт открыть: правый щелчок → «Открыть».
3. Установщик сам поставит что нужно (инструменты Xcode, Homebrew, Python 3.12, ffmpeg), создаст окружение
   и службу Studio на `http://127.0.0.1:18187/` и откроет «Первый запуск».

Повторный запуск того же файла обновляет Studio после `git pull` или нового архива; данные сохраняются.
Данные лежат в `~/Library/Application Support/H3 Studio` (папку можно сменить переменной `H3_MAC_DATA_DIR`).

## 2. «Первый запуск» — пять шагов

Страница `http://127.0.0.1:18187/setup.html` сверху показывает, что готово, а ниже на каждом шаге — поле и кнопку.

1. **SSH-ключ.** «Создать SSH-ключ» → «Скопировать открытый ключ» → вставить в аккаунт провайдера GPU
   (Vast.ai: Keys → SSH Keys). Токены Hugging Face не нужны: все модели открытые.
2. **GPU-сервер.** API-ключ Vast.ai → «Сохранить» → «Открыть „GPU и модели“» → выбрать предложение (от 96 ГБ
   видеопамяти) → «Арендовать» → «Установить». Сервер ставится с нуля (около часа, веса ~150 ГБ) и сам
   подключается к Studio туннелем. Свой сервер: `bash scripts/h3_new_server.sh --host root@HOST --port PORT`.
3. **MiniMax API** (необязательно): ключ — и в параметрах ролика появляется переключатель «Свой GPU / MiniMax API».
4. **Агенты** (необязательно): «Подключить» у Claude Code или Codex — агент получает инструменты Studio по MCP.
5. **Свои модели и воркфлоу**: любой граф ComfyUI становится формой Studio («Свои воркфлоу»).

Когда все пункты зелёные — откройте «Создать» и сгенерируйте первый ролик.

## Если что-то не так

- Лог службы: `~/Library/Logs/H3 Studio/service-error.log`.
- Перезапуск Studio: `launchctl kickstart -k gui/$(id -u)/com.minimax.h3-mac-studio`.
- Порт занят: `H3_STUDIO_PORT=18197 bash scripts/install_studio_on_mac.sh`.
- Лог установки сервера — на странице «GPU и модели», у операции «Установить».
- Проверка сервера без рендера: `bash scripts/verify_h3_server.sh --host root@HOST --port PORT`.
