# Монтажный движок Studio · сравнение с Ponder и план

Монтажный лист (`local_studio/edl.py`, `/api/edl/*`) собирает готовые шоты H3 в фильм: переходы, акценты,
звуковой дизайн, музыка, громкость. Агент в Studio (Claude/Codex по подписке) пишет лист через MCP
(`edl_toolkit`, `edl_from_shots`, `edl_plan`, `edl_render`) по правилам `EDIT_CRAFT` в `local_studio/agent_chat.py`.
Пользователь — в «Монтаже» (`/editor/`, таймлайн над тем же листом, `local_studio/montage.py`) или в «Весь фильм» → «Монтажный лист». Агент правит открытый монтаж через `montage_get` / `montage_update` / `montage_render`.

## Что умеет сейчас (2026-10-28)

- **Переходы:** 11 монтажных типов из `app/director_schema.json` (cut, cut_on_action, match_cut, jump_cut, smash_cut,
  whip_pan, pass_through, morph, dissolve, fade, sound_bridge = J-cut) и для любого шва — один из 60 видов xfade
  (`transition_effect`: наезд, вспышка белым, смаз движения, сдвиги, шторки, пикселизация, круг…).
- **Акценты на таймлайне** (`accents`): тряска с наездом (zoompan), резкий наезд (`zoom`), вспышка, глитч (RGB-сдвиг + шум), RGB-сдвиг (`chroma`), VHS-сбой, стробоскоп, удар размытием, ч/б удар, негатив.
- **Превью** (`POST /api/edl/renders?draft=1`): половина размера, быстрый x264, без прохода громкости и QC цвета; `DELETE /api/edl/renders/{id}` останавливает устаревшую сборку.
- **Стоп-кадр** в конце шота (`freeze_end`) — интро героя в духе Ричи.
- **Звуковой дизайн** (`auto_sfx`): встроенная библиотека из 13 синтезированных звуков (`local_studio/sfx_bank.py`:
  whoosh, whoosh_long, swish, impact, boom, hit, riser, riser_short, subdrop, reverse_swell, glitch, shutter, pop),
  каждый с точкой привязки к кадру. Свист — на whip pan, удар с нарастанием — на smash cut, затвор и удар — на стоп-кадр,
  глитч — на глитч. Свои файлы SFX (роль «Звуковой эффект») и звуки библиотеки по имени — в `sfx`.
- **Музыка:** громкость, вход/выход, автоприглушение под речь (sidechain).
- **Моушен-графика** (`graphics`, `local_studio/motion.py`, шаблоны `tools/motion/src`): NameCard — титр героя на
  стоп-кадре (`anchor: freeze`), KineticTitle, LowerThird, TitleCard, Captions. Remotion 4.0.535 рендерит каждый титр
  с прозрачностью (ProRes 4444) через установленный Google Chrome, кеш `<данные Studio>/motion/`; титр едет вместе
  со своим клипом и получает свой звук (удар, свист, «бум»). Установка: `cd tools/motion && npm ci`.
- **Цвет** (`local_studio/grade.py`): шот — выравнивание к эталонному шоту (перенос среднего и разброса по каналам,
  сила 0.7) и своя поправка (`clips[].grade`: экспозиция, температура, оттенок, контраст, насыщенность, вибранс);
  фильм — `grade` и лук (`look`, `look_intensity` 0.4–0.7): teal_orange, warm_film, cool_matte, high_contrast, bleach_bypass, golden_hour, noir,
  clean_neutral, pastel, vivid, vintage и 10 творческих LUT (`lut_*`, `local_studio/luts/`, Striped Purple). Лук франшизы задаётся в паспорте (`edit.look`), выравнивание включено там по умолчанию. После сборки
  `color_qc` по каждому шоту: пересвет (p99 > 0.97 и > 1 % белого), провал в чёрное (> 20 %), слишком тёмный шот.
- **Экспорт в монтажки** (`local_studio/nle_export.py`, `POST /api/edl/exports`): папка с `STUDIO.xml` (Premiere),
  `STUDIO.fcpxml` (Resolve, Final Cut), `media/` (шоты, стоп-кадры PNG, титры ProRes 4444, музыка, звуки — жёсткие
  ссылки), `look.cube` (лук фильма, 33³, совпадает с Studio ~40 дБ PSNR) и маркерами для того, что монтажка сама не
  повторит (тряска, глитч, xfade-виды, выравнивание цвета). Клипы стыкуются по середине шва, переход той же длины
  на шве. `POST /api/edl/exports/{id}/resolve` открывает таймлайн в запущенном DaVinci Resolve (скриптинг Local).
  Проверено импортом в Resolve 21.1 (оба формата); импорт XML в Premiere 26.5 вручную ещё не проверялся.
- **Финиш:** зерно и виньетка (`grain`, `vignette`), двухпроходная нормализация громкости EBU R128 −14 LUFS / −1 dBTP
  (`loudness`), проверка длительности и звука готового MP4.

## Ponder 1.1.85 против Studio

| Возможность | Ponder | Studio |
|---|---|---|
| Видеопереходы | 3: растворение, через чёрное, через белое | 11 монтажных + 60 видов xfade |
| Акценты (тряска, вспышка, глитч) | нет (только ключи позиции/масштаба) | есть |
| Стоп-кадр | есть (freezeFrame) | есть + звук затвора |
| Звуковые эффекты | из медиатеки, Epidemic/Artlist, генерация | авторасстановка по швам из своей библиотеки; свои файлы |
| Приглушение музыки под речь | вручную ключами громкости | автоматически |
| Громкость −14 LUFS | только правило в навыке | выполняется при каждой сборке |
| Ключевые кадры позиции/масштаба/прозрачности, рампы скорости | есть | **нет** — следующий этап |
| Титры, субтитры, lower third, кинетический текст (Remotion) | есть | есть: титр героя на стоп-кадре, кинетический заголовок, плашка, титульная карточка, субтитры по словам (Remotion, рендер с прозрачностью) |
| Цвет: экспозиция, баланс, CDL, луки, LUT, совпадение по цвету | есть | есть: 11 луков (3 франшизных), экспозиция, температура, оттенок, контраст, насыщенность, вибранс, выравнивание шотов по эталону, проверка экспозиции; LUT — этап |
| Монтаж под бит музыки | есть (сетка битов) | **нет** — этап |
| Расшифровка речи, субтитры по словам | облако AssemblyAI/Deepgram | **нет** — этап (локально) |
| Экспорт в Premiere (xmeml), Resolve (XML + мост), FCPXML, CapCut | есть | есть: Premiere (xmeml v4), Resolve/Final Cut (FCPXML 1.10), импорт в открытый Resolve одной кнопкой, LUT лука, маркеры; CapCut — нет |
| Стабилизация | есть | нет (H3-шоты не трясутся) |
| Генерация видео в кадре, раскадровка, франшизы, паспорт, сцена от агента | нет | есть |
