# Участки видео и аудиореференсов

В «Создать» кнопка ✂ на карточке видео/аудио открывает проигрыватель, шкалу
начала и точное поле секунд. Длина участка связана с длиной текущего шота.
По умолчанию берётся начало; начало можно перенести. Для исходника короче
шота доступная длина сохраняется, без выдуманного повторения движения.

`reference-excerpts.mjs` → Mac `/api/assets/{id}/excerpt` → FFmpeg на Mac →
отдельный immutable asset → подмена ID при постановке → manifest →
`HttpGpuTransport.submit` открывает именно обрезанный файл.
В проекте остаются оригинальные ID и выбранный `excerptStart`, поэтому
изменение длительности готовит другой участок, а повторный запрос использует кэш.
Выбранный диапазон также поступает в Context-IR и автономный snapshot для H3.
Существующие окна многокадровой сцены имеют приоритет над отдельным выбором видео;
аудио по-прежнему ограничивается длительностью шота.

В Motion Control выбор видео сразу готовит участок до 10 секунд. Кнопка ✂
сохраняет исходный ID и новое начало, заменяет рабочий videoId на clip ID.
В «Изменить видео» `resolveSource` готовит участок до 10 секунд перед первым
кадром; смена участка сбрасывает прежний кадр/утверждение/flow. Контекст и
видеогенерация получают clip ID, предпросмотр показывает этот же участок.

Обрезка перемещает FFmpeg seek до входа и кодирует только выбранное время.
Видео: H.264 CRF18, veryfast, исходная частота кадров; при наличии аудио — AAC192k.
Отдельное аудио: PCM WAV. Границы проверяются ffprobe, проверяются хеши исходника
и кэша, запись атомарная, подготовка защищена межпроцессным lock. Старые задания
и принятый путь только фото не переписываются. Новых зависимостей нет.

## Исправление выбора границ

Начало и конец теперь независимы: два ползунка на одной шкале, два точных поля,
выбор каждой границы по текущему кадру и отдельное воспроизведение выделения.
После «Использовать участок» вызывается реальный Mac excerpt API; clip ID
сохраняется для немедленного предпросмотра. `excerptDuration` передаётся в Create,
Context snapshot, Motion и Video Edit, не заменяется длиной генерации.
Весь исходник можно просматривать для выбора границ; ограничение воспроизведения
действует только у кнопки «Проверить участок».

Проверка: UI18197, видео5–9с и аудио20–24с, ffprobe обоих clips4.0с;
после reload обе границы сохранены. Test jobcc08da36 manifest содержит эти
четырёхсекундные файлы при10сек генерации. В рабочей18187 окно на настоящем
референсе позволило выбрать5–9с, пользовательский выбор не сохранялся.
Production generation не запускалась. JS-модули/HTML version bumped;
backend/API обрезки уже были активны, дополнительный restart не требовался.
