# Подписочный чат внутри Studio

Код коннектора: `integrations/subscription-bridge/`. Пока реализован браузерный адаптер **ChatGPT**.
Claude Code/Codex доступны только в режиме «Агент»; адаптеры обычных Claude/Gemini не реализованы.

В Studio три режима: агент, обычный чат, картинка. Два последних используют локальную очередь
`local_studio/subscription_bridge.py` и Chrome extension Manifest V3. Модельные API, ключи,
CLI агентов, извлечение cookies и приватные API чата не используются. Это автоматизация интерфейса
сайта, поэтому его изменения могут нарушить селекторы `chatgpt.js`.

## Одноразовое подключение

1. В Chrome открыть управление расширениями, включить режим разработчика и загрузить распакованную
   папку `integrations/subscription-bridge` из проекта. Расширение получает доступ к `chatgpt.com`,
   двум адресам локальной Studio на порту 18187, вкладкам и собственному хранилищу. Пароли/cookies оно не читает.
2. Войти в ChatGPT в этом профиле Chrome самостоятельно. Подписка должна предоставлять генерацию картинок.
3. После разрешённого перезапуска службы Studio открыть/обновить её страницу в том же Chrome.
4. Выбрать обычный чат или картинку, указать франшизу, написать запрос и отправить.

Работа пользователя остаётся в Studio. Технически расширение создаёт неактивную вкладку ChatGPT
для конкретного чата Studio; это исполнитель, не ссылка или ручная пересылка. Вкладку не нужно
редактировать или переводить в другую беседу. При изменении привязки выполнение останавливается.
Safari и встроенный браузер Codex это Chrome-расширение не исполняют.

## Контекст и результат

В запросе последние 12 сообщений Studio, паспорт выбранной франшизы, карточки названных героев,
перечень идей и полная карточка идеи, если в запросе есть её точное название. При упоминании героя
выбирается его фото «Персонаж целиком»; для лица/портрета — «Лицо героя». До шести фотографий,
каждая до 15 МБ. Если требуемый герой неоднозначен, пользователь должен выбрать франшизу;
одно имя героя не определяет её автоматически. Текущая постановка холста и полные тексты всех идей
автоматически не выгружаются. Большой контекст отклоняется, а не обрезается незаметно.

Ответ сохраняется в том же JSON-чате, изображения — в штатной библиотеке Studio с asset_id.
Ассистентские вложения отображаются в переписке. При возврате к агенту в его следующий запрос
добавляется история с asset_id, чтобы он мог прочитать результат через Studio MCP.
Импорт картинки не является художественной приёмкой, назначением кадра шоту или запуском видео.

## Сбои и ограничения

ID запроса постоянный; claim транзакционный, одна операция браузера одновременно. Взятое задание
не истекает и не генерируется повторно. Результат записывается идемпотентно, с проверкой токена;
результаты расширения переживают перезагрузку вкладки Studio. Если процесс браузера прервали между
отправкой и сохранением результата, нужна ручная сверка фоновой вкладки; автоматического повторения нет.
Активное задание блокирует агентский ход и удаление его чата. Автоматическое решение CAPTCHA,
вход, обход ограничений и переключение на платный API отсутствуют.

При отсутствии расширения Studio сохраняет ввод и показывает причину. Наличие расширения означает
доступность локального транспорта, а не авторизацию ChatGPT или доступ к ImageGen. Сервер не обещает
нулевой расход подписочного лимита: он лишь не запускает агентский CLI для этих сообщений.

## Проверено

Точечные тесты проверяют очередь, идемпотентность, неверный токен, отсутствие повторной отправки,
реальный импорт PNG, HTTP-обмен до исходного чата без агента, выбор референса и адаптер на mock DOM.
Изолированная Studio на 18207 запустилась и ответила на `/api/subscription-bridge/status`.
Реальные DOM ChatGPT, загрузка референсов и генерация ImageGen не проверены: Local browser use отключён
в Work settings. Расширение не устанавливалось, рабочая Studio не перезапускалась.
