# STUDIO — локальная режиссёрская студия

Эта страница обслуживается `local_studio.main` на Mac по адресу `http://127.0.0.1:18187/`. Открытие `index.html` через `file://` не поддерживает API загрузки; файловая версия автоматически перенаправляет на рабочий адрес.

Из корня проекта после установки зависимостей из `requirements.txt`:

```bash
H3_GPU_API_URL=http://127.0.0.1:18189 \
python3 -m uvicorn local_studio.main:app --host 127.0.0.1 --port 18187 --workers 1
```

`18189` — локальный SSH-forward к закрытому GPU API. Название продукта изменено только в интерфейсе: прежние пути данных и API сохранены. Данные Mac остаются в `~/Library/Application Support/H3 Studio` или в `H3_MAC_DATA_DIR`. Генерация использует self-hosted MiniMax H3 BF16 на сервере. Оригиналы и итоговые MP4 хранятся на Mac; референсы передаются на GPU для конкретного задания.

Интерфейс поддерживает русский и английский языки; выбор сохраняется в браузере. Импорт фото/видео/аудио, теги `<Picture N>`, `<Video N>`, `<Audio N>`, промпт, режиссёрские настройки, сцены и очередь остаются рабочими при смене языка. После постановки задания текущий промпт и настройки остаются для следующего варианта. Уже созданное задание хранит неизменяемый снимок промпта, манифеста и настроек. Удаление использованного файла явно помечает его тег в промпте и блокирует отправку до исправления. Muse multi-CUT пока доступен только как планирование и не отправляется как одно задание.

Кнопка паузы останавливает отправку следующих заданий, а ожидающее задание можно отменить. Активное задание прерывается через ComfyUI по его ID. Процент показывает этап сэмплинга; черновой кадр отображается, если ComfyUI присылает нативный JPEG-предпросмотр.

Проверка модели состояния: `node --test preview/h3-director/model.test.mjs`. Реальный MP4 требует отдельной отправки задания с промптом и референсами.
