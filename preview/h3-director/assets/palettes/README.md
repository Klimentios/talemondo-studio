# Цветовые пресеты H3 Studio

Здесь 12 оригинальных иллюстративных кадров, созданных для Studio 3 октября 2026 года. Это **не кадры из фильмов**, не изображения Lummi/Unsplash и не фотографии реальных камер. Каждый кадр вырезан из одного специально сгенерированного листа в отдельный JPEG 512 × 256. По восемь HEX-образцов на кадр получены из его пикселей локальной кластеризацией (квантизация RGB и выбор различимых частых цветов). Цвета могут не включать редкий небольшой акцент кадра. Настройки `temperature`, `saturation`, `contrast`, `shadows`, `highlights` — редакторская интерпретация изображения, а не измеренный LUT или профиль устройства.

Каталог: [`catalog.mjs`](./catalog.mjs). Все файлы изображений локальны. Каждый пресет имеет собственный кадр, название, подпись, образцы цветов и текстовую цель цветокоррекции. При пользовательской загрузке новое изображение должно остаться в локальном хранилище Studio; палитра извлекается на Mac через [`palette-extract.mjs`](../../palette-extract.mjs), после чего её можно редактировать и сохранить как пользовательский пресет. Цветовые HEX и словесная цель передаются вместе с заданием, но H3 не гарантирует точное попадание в каждый HEX без проверенного цветового узла/LUT и визуальной оценки результата.

## Почему не импортировали готовую фотобиблиотеку

| Источник | Что проверено | Вывод для встроенной библиотеки |
| --- | --- | --- |
| [Lummi Terms](https://www.lummi.ai/terms) и [License](https://www.lummi.ai/license) | Бесплатное использование в конечных продуктах; запрещены перепродажа/перераспространение изображений и компиляция похожего сервиса; условия запрещают автоматический сбор сайта. | Фотографии Lummi **не включены** в поставку Studio. Для интеграции их API нужен отдельный ключ и разрешённый сценарий. |
| [Unsplash License](https://unsplash.com/license) и [Terms](https://unsplash.com/terms) | Лицензия допускает обычное использование, но исключает компиляцию изображений для похожего сервиса; условия запрещают автоматизированный доступ без API. | Фотографии Unsplash **не включены** в поставку Studio. |
| [Wikimedia Commons reuse guide](https://commons.wikimedia.org/wiki/Commons:Reusing_content_outside_Wikimedia) | Каждый файл имеет собственную лицензию и условия атрибуции; требуется проверять страницу каждого файла. | Допустимый будущий источник отдельных материалов с постраничной проверкой и manifest, но для этого набора не использовался. |
| [Open Color](https://github.com/yeun/open-color) | MIT, готовая гамма для интерфейсов. | Подходит для UI-токенов; не является базой кинематографических кадров и не заменяет режиссёрский пресет. Не импортировали. |
| [d3-scale-chromatic](https://github.com/d3/d3-scale-chromatic) | ISC, числовые шкалы для графиков. | Не подходит для кадра с содержательной цветокоррекцией. Не импортировали. |

Оригинальные кадры в этом наборе получены генерацией под Studio, поэтому сторонняя лицензия на стоковые фото к ним не применяется. Этот README не утверждает прав на пользовательские загрузки и не присваивает права на работы третьих лиц.
