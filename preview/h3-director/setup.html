H3 Studio

Первый запуск

Пять шагов до первого ролика. Сверху — что уже готово; каждый пункт ниже исправляется кнопкой.

Готовность

1. SSH-ключ

Нужен один раз. Токены и регистрации на Hugging Face не нужны: все модели открытые.

SSH-ключ

Им Studio заходит на GPU-сервер. Создайте и добавьте открытый ключ в аккаунт провайдера (Vast.ai: Keys → SSH Keys).


      

    

    

      
2. GPU-сервер

      
Нужна NVIDIA от 96 ГБ видеопамяти. Проще всего — аренда на Vast.ai прямо из Studio: вставьте API-ключ,
        откройте «GPU и модели», выберите предложение и нажмите «Установить». Сервер поставится с нуля (≈1 ч, веса ~150 ГБ)
        и подключится к Studio сам.

      

        API-ключ Vast.ai ✓ сохранён
        

      

      
Открыть «GPU и модели»

      

        У меня свой сервер
        
Откройте «GPU и модели» → «Сервер», вставьте SSH-команду сервера (например, из панели RunPod или Vast)
          и нажмите «Установить H3 на этот сервер». Если сервер уже работает, укажите адреса туннеля:

        

          
          
          

        

      

    

    

      
3. MiniMax API необязательно

      
Генерация в облаке MiniMax без своего GPU (768P, оплата по тарифу MiniMax). Включается переключателем
        «Свой GPU / MiniMax API» в параметрах ролика.

      

        Ключ MiniMax API ✓ сохранён
        

      

    

    

      
4. Агенты необязательно

      
Claude Code и Codex управляют Studio через MCP-сервер h3-studio: собирают сцены, ставят рендер
        по вашему разрешению, проверяют ролики. Работают по вашей подписке.

      

    

    

      
5. Свои модели и воркфлоу

      
Любой граф ComfyUI с любой моделью становится формой Studio в «Свои воркфлоу»; пакеты узлов и веса — в «Узлы и модели».
