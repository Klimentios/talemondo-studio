# Общие навыки агентов (Claude и Codex)

Общее правило проверки для всех навыков этого проекта: минимальное число тестов, напрямую
проверяющих изменённое поведение и реальный риск. Полный `scripts/check.sh` — только перед
релизом/деплоем, после изменения общего контракта с широким влиянием или при конкретной
регрессии. Не запускай его автоматически после каждой правки и не повторяй тесты без причины.

Источник — эта папка (в git). В домашние каталоги агентов навыки подключены симлинками:
`~/.codex/skills/<имя>` и `~/.claude/skills/<имя>` → `<репо>/skills/<имя>`.
Правишь навык — правь здесь и коммить; оба агента сразу видят одно и то же.

| Навык | Когда |
|---|---|
| `minimax-video-production` | единый вход для H3-видео: мультсцены, перенос движения, замена героев, работа с результатом и QC; точный IR и реестр замен читаются по необходимости |
| `h3-fast-deploy` | новый GPU-сервер из R2 (`infra/h3_up.sh`), подключение Studio, новый снимок |
| `h3-camera-shots` | сторонний (LoopForge, MIT, см. `SOURCE.md`): 29 проверенных планов камеры на 12 примитивах H3; по нему записаны пресеты камеры `app/director_schema.json` |
| `h3-shot-iteration` | сторонний (LoopForge, MIT): разбор неудачного движения камеры и что менять в следующем дубле |
| `h3-prompt-writing` | промпты H3 в официальных форматах (6 секций Ref2VA и базовые режимы) |
| `cinematic-director` | ремесло режиссёра: подтекст, мизансцена, жанровые движки, монтаж, QC (внешний, DirectorSKILL, MIT) |
| `visual-dramaturgy` | драматургия шота: закон трёх деталей, три задачи шота, ритм, монтажные паттерны (внешний, smixs/visual-skills, CC-BY 4.0 — указывать автора) |

Внешние навыки установлены 24.10.2026 после ручной проверки (без скриптов). Обновлять только вручную с повторной проверкой; `minimax-video-production` ведёт H3-процесс, а `h3-prompt-writing` даёт точный IR-шаблон, когда он нужен.

Новый навык: папка `<имя>/SKILL.md` с YAML `name` + `description` (формат общий для Claude и Codex),
затем `bash skills/link.sh`. Хосты/порты/снимки в навыки не вписывать — ссылаться на `docs/STATE.md`.
Секреты — никогда.
